📁 phase-02-classical-ml / 01-ml-concepts / Concepts first — code after. Understand before implementing.
▶ Watch📖 Read
Core ML Concepts to Understand concepts.py
  • What is machine learning: giving computers the ability to learn from data without being explicitly programmed
  • Supervised learning: input → label pairs. Model learns the mapping. Example: email → spam/not spam
  • Unsupervised learning: input only, no labels. Model finds patterns. Example: customer segments
  • Training set, validation set, test set — why you need all three and what each is for
  • Features (X): inputs to the model. Labels (y): what you're predicting
  • Loss function: measures how wrong your model is. Goal: minimize this.
  • Gradient descent: algorithm that minimizes loss by adjusting model parameters step by step
  • Learning rate: step size in gradient descent. Too large = overshoot. Too small = too slow.
  • Overfitting: model memorizes training data, fails on new data — too complex
  • Underfitting: model too simple, can't capture patterns even in training data
  • Bias-variance tradeoff: high bias = underfitting. High variance = overfitting. Find the balance.
  • Hyperparameters: settings you choose before training (learning rate, depth). Parameters: learned during training (weights)

📁 phase-04-llms-genai / 01-llm-fundamentals / Understand what an LLM actually is before using APIs
▶ Watch📖 Papers
How LLMs Actually Work llm_concepts.py
  • Transformer architecture: encoder-only (BERT for understanding), decoder-only (GPT for generation), encoder-decoder (T5 for translation)
  • Self-attention: Query, Key, Value matrices. Attention score = softmax(QK^T / √d_k) × V
  • Multi-head attention: run attention multiple times in parallel, different learned projections
  • Positional encoding: how the model knows word order (sin/cos functions added to embeddings)
  • Tokenization: BPE (Byte Pair Encoding) — text → subword tokens → integer IDs
  • Context window: maximum tokens model can process at once — why it's limited
  • Pretraining: next token prediction on internet-scale text — this is how GPT learned everything
  • Temperature: controls randomness. 0 = deterministic, 1 = balanced, 2 = very random
  • Top-k and top-p sampling: limit token candidates to most likely k tokens, or top probability mass p
  • Read the paper: "Attention Is All You Need" (2017) — the original transformer paper

📁 phase-04-llms-genai / 04-rag-systems / Install: pip install langchain chromadb sentence-transformers
⌨ PyCharm🎯 Build
RAG — Retrieval Augmented Generation rag_pipeline.py
  • The problem: LLMs don't know your private documents and have a knowledge cutoff date
  • The solution: retrieve relevant chunks from your documents, inject into the LLM prompt as context
  • Step 1 — Load documents: PDF, TXT, Word files using LangChain document loaders
  • Step 2 — Chunk: split documents into smaller pieces. RecursiveCharacterTextSplitter(chunk_size=500)
  • Step 3 — Embed: convert each chunk to a vector using a sentence transformer model
  • Step 4 — Store: save vectors in ChromaDB (local) or Pinecone (cloud)
  • Step 5 — Retrieve: when user asks a question, embed the question, find top-k similar chunks
  • Step 6 — Generate: send question + retrieved chunks to LLM. It answers using your documents.
  • Chunking strategies: fixed size, recursive, semantic (by meaning) — each affects quality
  • Reranking: use a cross-encoder to reorder retrieved chunks by relevance
  • Evaluation: RAGAS framework — measures faithfulness, answer relevance, context recall

AI System Design Thinking

AI Safety & Responsible AI
  • Hallucination: why LLMs confidently state false facts — how to mitigate with RAG and verification
  • Prompt injection: user input that hijacks system prompt — detect and sanitize inputs
  • Bias in training data: models learn stereotypes — how to audit and measure
  • PII (Personally Identifiable Information): never log user data carelessly. Use Presidio to detect PII.
  • Content moderation: OpenAI Moderation API, custom classifiers — filter harmful outputs
  • Red teaming: deliberately try to make your model produce harmful outputs — before users do
  • Guardrails: input validation + output filtering. guardrails-ai library.
